디자인 시안 아카이브 관리

새 시안은 항상 새 폴더로 올라가고, 이미 올린 시안 파일은 고치거나 지우지 않습니다. 목록에서 빼고 싶으면 "숨기기"를 쓰세요.

1. GitHub 연결

저장 버튼을 누르면 GitHub 저장소에 바로 커밋되고, Vercel이 자동으로 배포합니다(1~2분). 토큰은 이 브라우저에만 저장됩니다.

2. 새 시안 올리기

zip 파일을 고르면 안에 있는 index.html들을 찾아 시안 버튼을 자동으로 만듭니다. 올린 파일은 archive/날짜-시간-이름/ 새 폴더에 들어갑니다.

zip을 고르면 여기에 나옵니다.

3. 아카이브 목록 관리

제목·설명·날짜·순서·공개 여부만 바꿉니다. 내용을 고치면 수정일이 오늘로 바뀝니다. 시안 파일 자체는 건드리지 않습니다.
