업무 아카이브 관리

디자인 시안·기획서를 프로젝트 → 버전 → 시안 순서로 관리합니다. 올린 파일은 고치거나 지우지 않고, 새 버전은 항상 새 폴더로 올라갑니다.

1. 연결

서버 설정이 없을 때만: GitHub 토큰으로 연결

2. 시안·기획서 올리기

zip을 고르면 안의 index.html을 찾아 시안 버튼을 만듭니다. 파일은 archive/날짜-시간-이름/ 새 폴더에 들어갑니다.

zip을 고르면 여기에 나옵니다.

3. 프로젝트·버전 관리

이름·팀·설명·순서·공개 여부와 확정안을 정합니다. 휴지통은 목록에서만 빼고 파일은 남겨서 되살릴 수 있습니다. 바꾼 뒤 저장을 눌러야 반영됩니다.
