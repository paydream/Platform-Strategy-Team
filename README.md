## 수정할 때 알아둘 것

- **썸네일 카드 내용 바꾸기**: `js/main.js`의 `CARDS` 배열만 고치면 됩니다. 등급(`premium`/`member`/`free`), 태그(`ai`/`update`/`update-light`), 후기 배지(`isNew`로 N 표시) 다 여기서 바꿉니다.
- **카드01 (보관 중인 프롬프트 카드)**: 예전 '예스폼 추천 콘텐츠' 탭에 쓰던 프롬프트 카드([Figma 5451:53036](https://www.figma.com/design/UEFYzhh4vwD96r3A0J9TwH/?node-id=5451-53036))를 **카드01**이라는 이름으로 `_보관/카드01/`에 옮겨 두고 메인에서는 지웠습니다. `_보관/카드01/index.html`을 열면 카드만 따로 볼 수 있습니다. 다시 메인에 쓰려면 이 폴더의 템플릿(index.html 안 `prompt-card-template`), `card01.css`, `card01.js`의 데이터·렌더 함수를 메인으로 옮기면 됩니다. 카드 최소 폭 420px 기준이라 1920에서 1행 4개, 2560에서 5개입니다.
- **업무분야 칩 색**: `FIELD_TONE`에서 업무분야 첫 단어로 컬러를 고릅니다 ([Figma 5281:21380](https://www.figma.com/design/UEFYzhh4vwD96r3A0J9TwH/?node-id=5281-21380) 관심분야 컬러차트 9종). 칩 배경은 차트 4번째 열, 글자는 3번째 열 색입니다. 단, 공공행정 글자는 차트 색(#FFAB4B)이 배경과 대비가 1.8:1로 너무 낮아 #B45309(4.8:1)로 교정했습니다. 색은 `tokens.css`의 `--field-*`, 클래스는 `.tone--*`로 시안 01 패키지 카드와 카드01이 같이 씁니다 (시안 02는 안 씀).
- **패키지 카드 내용 바꾸기**: `js/main.js`의 `PACKAGE_CARDS`를 고치면 됩니다. 한 줄에 카드 하나씩 `no`(번호), `industry`(업종 → 첫 번째 칩), `field`(업무분야 → 두 번째 칩 + 아이콘), `title`, `desc`를 넣습니다. 지금 20개가 들어가 있고, **새로고침할 때마다 순서가 랜덤으로 섞여서** 나옵니다 (`renderPackageCards`의 `shuffle`). 번호가 없는 항목은 `no: null`로 넣었습니다.
- **업무분야 아이콘**: 예스폼 에디터 피그마의 업무분야 아이콘 9종([Figma 5490:40913](https://www.figma.com/design/UEFYzhh4vwD96r3A0J9TwH/?node-id=5490-40913))을 `assets/icons/cat-*.svg`로 넣었습니다. `FIELD_ICON`이 업무분야 이름의 첫 단어(법무·영업·공공행정·생산·HR관리·총무·회계·AI·현장)로 아이콘을 찾기 때문에 `총무·경영지원·일반사무`처럼 표기가 조금 달라도 연결됩니다. 못 찾으면 법무 아이콘이 나옵니다.
- **패키지 카드 칩·아이콘 배경**: 시안 01은 첫 번째 칩(업종)이 회색 `--gray-lt-03`(#f1f2f4), 두 번째 칩(업무분야·관심분야, `.tone--*`)이 위 관심분야 컬러입니다. 시안 02는 두 칩 모두 파란 칩입니다(위 시안 02 설명 참고). 칩 사이 간격은 시안 01이 **8px**(칩 배경 없음), 시안 02가 **4px**입니다(`.package-card__chips` gap). 아이콘 박스 배경은 `background/bg` 토큰(`--bg-soft`, #f6f8fa)입니다.
- **패키지 카드 글자 넘침**: 제목은 1줄, 설명은 2줄까지 보이고 나머지는 "…"로 줄입니다. 칩도 한 줄 유지라서 업무분야 칩이 길면 뒤쪽이 "…"로 줄어듭니다 (카드 높이 288 고정).
- **패키지 카드 채우기·더보기**: 4번째 줄까지 꽉 차도록 카드를 랜덤으로 더 넣습니다. 시안 01은 카드 31 + 광고 1 = 32칸(`PACKAGE_CARD_SLOTS`) → 8열 × 4줄, 7열일 때는 28칸만 보이고, 지금은 라인 아이콘 업무분야 카드 9장을 섞어 반복합니다. 시안 02는 카드 20 + 중복 4 + 광고 1(`PACKAGE_FILL_DUPLICATES`)입니다. 같은 제목 카드가 바로 옆에 붙지 않게 섞습니다. 그리드 아래 "프롬프트 더보기" 뉴트럴 버튼(가로 160 · 높이 48, 아이콘 없음 — 시안 01·02 공통)은 모양만 있고 아직 동작은 연결하지 않았습니다.
- **패키지 탭 광고 카드**: `js/main.js`의 `PACKAGE_AD`(이미지·링크·대체문구)로 바꿉니다. 1번째 줄 맨 오른쪽 칸에 고정되고, 창 크기가 바뀌어 열 수가 달라지면 다시 그 자리로 옮깁니다. 카드 높이는 옆 카드에 맞추고, 이미지는 왼쪽·아래 기준(`object-position: left bottom`)이라 넘치는 부분은 오른쪽·위부터 잘립니다(시안 01·02 공통).
- **하단 섹션(놓치면 후회할 콘텐츠)**: 전달받은 화면 캡처를 그대로 이미지로 넣었습니다(`assets/images/section-recommend.png`, 오른쪽 상담 위젯은 잘라냄). 카드별 링크가 필요하면 HTML로 다시 만들어야 합니다.
- **탭과 화면 연결**: 탭 버튼의 `aria-controls`가 보여줄 패널을 정합니다 (`panel-package` / `panel-thumb`). 처음 열리는 탭은 `is-active` 클래스가 붙은 탭(지금은 프롬프트)입니다.
- **색·폰트 크기 바꾸기**: `css/tokens.css`에서 바꾸면 전체에 반영됩니다.
- **카드 테두리**: 피그마는 테두리가 폭을 차지하지 않아서(stroke inside) CSS에서도 `::after` 오버레이로 그렸습니다. `border`로 바꾸면 썸네일이 2px 줄어듭니다.

## 피그마에 없어서 임시로 넣은 것

- **썸네일 카드 5줄 · 콘텐츠 더보기** (시안 01·02 공통): 썸네일 탭은 화면 폭에 따른 한 줄 개수 × **5줄**만 보입니다 (1920: 7 × 5 = 35장, 2560: 8 × 5 = 40장, 1440: 5 × 5 = 25장). `js/main.js`의 `THUMB_CARD_COUNT`(40장)만큼 `CARDS`를 반복해 만들고, 넘치는 카드는 `css/style.css` 맨 아래 nth-child 규칙으로 숨깁니다. 그 아래 뉴트럴 버튼 **"콘텐츠 더보기"**(프롬프트 더보기와 같은 모양, 동작은 아직 없음)를 넣었습니다.
- **썸네일 카드 간격**: 피그마는 40이지만 시안 01·02 모두 모든 썸네일 탭을 **24**로 바꿨습니다 (40 → 30 → 24, `tokens.css`의 `--grid-gap`). 720px 이하는 12입니다.
- **반응형**: 피그마는 2560 한 사이즈뿐이라 화면 폭에 따라 한 줄 카드 수를 정했습니다. 좌우 여백 50은 그대로입니다.

  | 화면 폭 | 1행 카드 수 | 카드 폭 |
  |---|---|---|
  | 2201px 이상 (2560) | 8개 | 약 284~286px (피그마는 272.5px · 간격 40) |
  | 1821~2200px (**1920**) | **7개** | 약 237~239px |
  | 1561~1820px | 6개 | |
  | 1301~1560px | 5개 | |
  | 1201~1300px | 4개 | |
  | 721~1200px | 3개 | |
  | 720px 이하 | 2개 | |

  카드가 좁아지면 썸네일 태그가 찜 하트를 가리지 않게 태그 폭을 제한했습니다 (넘치면 말줄임).
- **찜 활성 상태**: 하트 눌렀을 때 디자인이 없어서 색만 바꿔 뒀습니다. 개선안 나오면 `.card__fav[aria-pressed="true"]` 부분을 교체하세요.
- **패키지 카드 하단**: 시안 01은 복사·찜 아이콘 없이 "바로 생성하기" 버튼만 카드 폭에 꽉 차게 둡니다. 버튼 마우스오버 색(#f1f2f4)은 시안에 없어 임시로 넣었습니다.
- **예스폼 AI 모드**: 토글 상태값(`data-mode`)만 바뀌고 화면은 그대로입니다.
- **썸네일 이미지**: 실제 서비스에선 서버에서 받는 이미지라 피그마 화면을 2배율로 렌더해 넣었습니다. 원본 해상도가 필요하면 피그마에서 따로 내보내 교체하세요.
