# 예스폼싸인 메인 — 최종

`index.html` 을 브라우저로 열면 됩니다. HTML 은 이 파일 하나뿐입니다. (2026-10-26 · 헤더 교체 2026-10-27)

화면 아래 가운데 버튼으로 **시안01 · 시안02** 를 바꿔 봅니다. 버튼에서 ←/→ 키로도 바뀌고, 주소 뒤 `#01` / `#02` 로 바로 열 수 있으며, 마지막으로 본 시안을 기억합니다.

## 폴더

```
index.html        시안 전환 화면 + 시안01 · 시안02 내용 (맨 아래 <template>)
css/style.css     시안01 스타일 — 맨 아래 "[내부]" 블록이 공통 내부 그리드 정의
css/style2.css    시안02 스타일
css/header.css    상단 헤더 (두 시안 같이 씀)
js/main.js        계약서 분야 버튼 · 로그인 창 · [내부] 경계 보기 · 시안02 제품 화면 등장 (두 시안 같이 씀)
images/           그림 (두 시안에서 쓰는 것) — logo.png · logo-sign-header@3x.png 는 이제 안 씀, 지워도 됨
```

## 시안 내용 고치는 곳

| 시안 | index.html 안의 위치 | 스타일 |
|---|---|---|
| 시안01 | `<template id="sian-01-body">` | `css/style.css` |
| 시안02 | `<template id="sian-02-body">` | `css/style2.css` |

- 시안마다 따로 화면(iframe)을 만들어 그 안에 내용을 넣기 때문에 두 스타일이 서로 섞이지 않습니다.
- 그림 · 스타일 · 스크립트 경로는 `index.html` 기준(`images/…`, `css/…`, `js/…`)입니다.
- `<template id="sian-0X-head">` 에는 글꼴과 스타일 파일 연결만 들어 있습니다. (시안 스타일 + `css/header.css`)
