# 예스폼싸인 메인 — 최종

`index.html` 을 브라우저로 열면 됩니다. HTML 은 이 파일 하나뿐입니다. (2026-10-26)

화면 아래 가운데 버튼으로 **시안01 · 시안02** 를 바꿔 봅니다. 버튼에서 ←/→ 키로도 바뀌고, 주소 뒤 `#01` / `#02` 로 바로 열 수 있으며, 마지막으로 본 시안을 기억합니다.

## 폴더

```
index.html        시안 전환 화면 + 시안01 · 시안02 내용 (맨 아래 <template>)
css/style.css     시안01 스타일 — 맨 아래 "[내부]" 블록이 공통 내부 그리드 정의
css/style2.css    시안02 스타일
js/main.js        계약서 분야 버튼 · 로그인 창 · [내부] 경계 보기 · 시안02 제품 화면 등장 (두 시안 같이 씀)
images/           그림 46개 (두 시안에서 쓰는 것만)
```

## 시안 내용 고치는 곳

| 시안 | index.html 안의 위치 | 스타일 |
|---|---|---|
| 시안01 | `<template id="sian-01-body">` | `css/style.css` |
| 시안02 | `<template id="sian-02-body">` | `css/style2.css` |

- 시안마다 따로 화면(iframe)을 만들어 그 안에 내용을 넣기 때문에 두 스타일이 서로 섞이지 않습니다.
- 그림 · 스타일 · 스크립트 경로는 `index.html` 기준(`images/…`, `css/…`, `js/…`)입니다.
- `<template id="sian-0X-head">` 에는 글꼴과 스타일 파일 연결만 들어 있습니다.

## 버튼 · 탭 모서리

- 두 시안의 버튼 · 탭 모서리는 모두 **8** (2026-10-26 통일)
  - 시안01 분야 버튼(취업/고용 …) 12 → 8 · 전자도장 카드 버튼(싸인 만들기 · 일반 도장 · 서명 관리) 16 → 8 · 푸터 사이트맵 100 → 8
  - 자동결제 버튼 둘레에 퍼지는 빛도 8 고정 (예전엔 12에서 커지며 24까지 둥글어짐) · 시안 전환 버튼 · 바도 8
  - 화면 폭 전체 배너는 버튼이 아니라 띠라서 모서리 0 그대로

## [내부] 그리드

- 폭 1280px 고정, 안쪽 좌우 여백 10px → 콘텐츠 1260px (반응형 아님, 고정 px)
- 폭을 바꾸려면 `css/style.css` · `css/style2.css` 맨 아래 `--ys-inner`(1280px) · `--ys-gutter`(10px) 두 값만 고치면 됩니다.
- 경계 보기: 시안 화면을 한 번 누른 뒤 키보드 **G** → [내부] 끝은 빨간 실선, 콘텐츠 끝은 빨간 점선 (다시 G 를 누르면 꺼짐)

## 시안01

1. GNB
2. 히어로 — 계약 4단계 카드

## 아직 임시인 것

- 표준 계약서 섹션: 분야마다 4번째 칸은 첫 번째 계약서를 임시로 복사해 둠 (`js/main.js` 의 `TEMP_COPY`). 물건거래 · 하청/용역 · 기타문서는 그림 대신 임시 계약서(제목 · 조항)를 그려서 보여 줌 — 그림을 받으면 `YS_TABS` 에 넣고 `TEMP_COPY` 를 `false` 로
- GNB 로그인 버튼은 아직 로그인 창과 연결되어 있지 않음
