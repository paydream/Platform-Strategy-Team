  3. 진행중

    계약서가 전송되어 서명 절차가 진행되고 있는 상태

  4. 완료됨

    모든 서명이 끝나 계약이 정식으로 체결된 상태

  5. 취소됨

    당사자 중 한명의 취소로 계약이 중단된 상태

법적 효력 100% 보장
종이 계약보다 더 철저하게 기록하고 안전하게 보관합니다

  • 감사추적인증서

    계약 체결 과정에서 발생하는 모든 상태를 기록하고 보관하여 계약의 무결성을 보장하고 사후 검증이 가능하도록 지원합니다.

  • 휴대폰 인증

    계약 당사자의 본인 확인을 위해 휴대폰 인증을 적용하여 신원을 정확하게 검증하고 위·변조를 방지합니다.

  • 접근 암호 설정

    계약서를 열람할 수 있는 권한을 암호로 제한하여 승인된 사용자만 접근할 수 있도록 보안성을 강화합니다.

  • SSL 암호화

    데이터 전송 과정 전반을 최신 SSL  방식으로 암호화하여, 외부 해킹과 불법 접근으로부터 계약서를 안전하게 보호합니다.
