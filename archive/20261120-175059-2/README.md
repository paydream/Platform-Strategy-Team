- 유형 라벨: `type type--bulk`(대량 전송) · `type type--normal`(일반 계약)
- 역할 라벨: `role`(정보를 미리 입력한 역할, 실선 — `data-name` · `data-contact` 에 이름 · 연락처) · `role role--empty`(보낼 때 입력, 점선)
- 핀 켠 상태: `pin is-on` + `aria-pressed="true"`
- 처음부터 펼쳐 둘 행: `row is-open`

- 라벨 목록 — 줄 높이 60 · 4줄을 넘으면 목록 안에서 스크롤 (머리줄 고정) · 맨 위 체크박스 = 보이는 라벨 모두 선택
- 연필 → 그 줄이 입력 칸(지우기 X) + [취소] [수정] · Enter 수정 · Esc 취소 · 같은 이름이 있으면 빨간 테두리
- 휴지통 → 그 줄이 회색 바탕 + 주황 안내("해당 라벨을 삭제하시겠습니까? 계약서는 삭제 없이 기본 라벨로 변경됩니다.") + [취소] [삭제]
  [삭제] → 목록에서 빠지고, 그 라벨이 붙어 있던 계약은 라벨 없음("-")
- 라벨명(최대 20자) + [라벨 추가하기] 또는 Enter → 목록 맨 아래에 추가되고 체크됨 · 같은 이름이면 빨간 테두리 + "이미 있는 라벨명입니다." (이 안내는 시안에 없어 새로 씀)
- [설정하기] → 체크한 라벨을 대상(목록의 체크한 행 · 추가 메뉴를 연 행 · 상세 · 전송 설정)에 붙이고 닫힘 · [닫기] · 바깥 · Esc → 붙이지 않고 닫힘
  열 때는 지금 붙은 라벨이 체크된 채로 열림 (대상이 여럿이면 모두에 붙은 라벨만)
- 라벨 추가 · 수정 · 삭제는 누르는 즉시 반영 ([닫기]를 눌러도 남음) · 같은 탭의 다른 화면에서도 같은 목록 (sessionStorage `signLabels` · 탭을 닫으면 처음 예시 5개로)
