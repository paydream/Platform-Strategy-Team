## 동작

- 에디터 상단 왼쪽 **"문서에 문제가 발생했나요?"**(밑줄 글자 버튼)를 누르면 딤드(검정 60%) + 의견 보내기 모달이 뜹니다.
- 모달 구성 (수정1): 제목 · 설명 → 구분선 → "어떤 문제가 있나요?" 2 × 3칸 → 첨부 칸 → 아래 안내 "오류 확인을 위해 지금 보고 계신 문서 정보도 함께 전달돼요." (380 × 538)
  - 예전 시안의 파란 체크 줄("지금 보고 계신 문서 정보도…")은 없어지고, 문서 정보는 늘 함께 보내는 것으로 바뀜.
  - 문제 칸은 여러 개 고를 수 있고, 고른 칸은 파란 테두리 + 체크. **"기타"를 고르면 "어떤 문제인지 적어주세요." 입력칸이 열립니다.** 기타를 풀면 다시 닫힘.
  - **첨부 칸에 마우스를 올리면 (수정2_호버)** 회색 점선 → 파란 실선(#0472e3) + 연한 파랑 바탕(#f6fafe). 파일을 끌어 올렸을 때도 같은 모양.
  - 첨부 칸을 누르거나 파일을 끌어다 놓으면 **파일 이름 + 휴지통** 줄로 바뀝니다. 휴지통을 누르면 다시 첨부 칸으로. (파일은 한 개)
- **닫기** = 모달 닫힘. **보내기** = 모달 닫히고 아래에 "의견을 보냈어요. 빠르게 확인해 고칠게요." 안내(토스트)가 2.5초 동안 떴다가 사라집니다.
- 딤드를 누르거나 ESC를 눌러도 닫히지 않습니다 (적던 내용이 실수로 사라지지 않게 · 메인_편집 가이드 모달과 같은 규칙).
- 모달을 다시 열면 처음 상태(고른 칸·적은 글·첨부 파일 모두 비움)로 돌아갑니다.
- 실제 전송은 없습니다. 보내기를 누르면 고른 값이 브라우저 콘솔에 찍힙니다 (`js/main.js`의 submit 부분에 서버 전송을 붙이면 됨).
