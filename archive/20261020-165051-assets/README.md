## 여는 법

- `index.html` 하나를 브라우저로 열면 됩니다. 열자마자 템플릿 화면 위에 딤드(검정 60%) + 등급 모달이 떠 있습니다.
- 화면 위 가운데 **시안 01 · 시안 02 탭**으로 두 디자인을 바꿔 봅니다. 고른 탭은 기억해서 새로고침해도 그대로 열립니다(처음엔 시안 01).

## 동작

- **오른쪽 위 X**를 누르면 닫힘. 닫은 상태에서 **탭을 누르면 그 시안으로 다시 열림**.
- **딤드를 누르거나 ESC**를 눌러도 닫히지 않음 (메인_편집 · 메인_의견안내 모달과 같은 규칙).
- 닫은 뒤 **템플릿 카드(제목 · 바로 편집하기)를 누르면 지금 고른 시안으로 다시 열림** — 무료 회원이 프리미엄 서식을 누른 상황.
- "예스폼 프리미엄 구독하기"는 화면 확인용이라 실제 이동은 없음.

## 만든 방식

- 배지 · 제목 · 설명 · 카드 제목 · 체크 목록 · 구독 버튼 · X는 **HTML 글자/SVG**로 넣음 (Figma 값 그대로).
- 카드 안 그림(문서 미리보기 · 아이콘 · 상자 등)과 디자인1 오른쪽 위 꾸밈은 Figma에서 **글자를 뺀 채 2배 PNG**로 내보냄 → `assets/images/grade/`.
- 템플릿 화면 파일(css/style.css · css/tokens.css · js/main.js · assets)은 `템플릿페이지` 폴더와 같음. 모달과 시안 탭만 `css/grade-modal.css` · `js/grade-modal.js`를 따로 씀.
- 시안 탭은 Figma에 없는 확인용 장치. 딤드보다 위에 떠 있고, 화면이 낮을 때 모달이 탭에 가리지 않게 딤드 위아래 여백을 84로 둠 (모달은 그대로 화면 가운데).
