# 예스폼 에디터 — 메인 편집 화면 + 안내 모달

`index.html`을 브라우저로 열면 됩니다. 1920 × 1080 화면에서 Figma와 같은 위치·크기로 보입니다.

## 동작

- 화면을 열면 **딤드(검정 60%) + 에디터 가이드 모달 1/4**가 떠 있습니다.
- 가이드 4단계 (Figma 섹션 [6514:51221 "261015_에디터 가이드 모달"](https://www.figma.com/design/UEFYzhh4vwD96r3A0J9TwH/?node-id=6514-51221)):
  1. 예스폼 서식을 나만의 문서로 완성하세요 — [다음]
  2. 추천 프롬프트로 초안을 생성하세요 — [이전] [다음]
  3. 예스폼 에디터에서 자유롭게 문서를 작성하세요 — [이전] [다음]
  4. 작성한 계약서, 바로 전자계약하세요 (+ 회색 안내 "문서 용량은 5MB 이하만 가능합니다.") — [이전] [에디터 시작하기] → 누르면 닫힘 · 2026-10-15 Figma 6503:50905 문구 반영
- **딤드를 눌러도 아무 일 없음** (ESC 키로도 안 닫힘).
- **모달 오른쪽 위 X를 누르면 어느 단계에서든 닫힘** → 뒤의 에디터 화면을 쓸 수 있게 됩니다. 다시 보려면 새로고침.
- 모달이 떠 있는 동안 뒤 화면은 눌리지 않고, 키보드 Tab 초점도 모달 안에서만 돕니다.
- 단계별 그림·제목·설명·버튼 글자는 `js/main.js`의 `GUIDE_STEPS`에서 바꿀 수 있습니다.
- 모달 크기는 섹션 디자인대로 **단계마다 520 × 510**(그림 260 + 글 영역 250 · 글 묶음 높이 122 고정 → 버튼 위치 같음). 처음 목업(6514:51584)은 524였는데 섹션 기준으로 맞췄습니다. 4단계는 용량 안내가 한 줄 더 있어 Figma처럼 버튼 쪽으로 조금 더 내려옵니다.
