## 탭별 동작
**싸인 그리기**
- 그리기 칸에 마우스·펜·손가락으로 그리면 안내 문구가 사라지고 [만들기]가 켜짐
- 오른쪽 위 둥근 버튼(다시 그리기)을 누르면 칸이 비고 [만들기]가 다시 꺼짐

**싸인 만들기 · 일반 도장 · 법인 도장**
- 처음: 만드는 방법 + 이름 입력칸 + [싸인 만들기]/[도장 만들기]
- 이름을 넣고 버튼(또는 Enter)을 누르면 만들어진 목록이 열리고 버튼 글자가 [다시 만들기]로 바뀜
- 카드를 하나 고르면 체크가 켜지고 [저장하기]가 켜짐 (한 개만 고름)
- 입력칸 상태: 기본 · 마우스 올림(#F6F7F8) · 입력 중(테두리 #1B52ED) — 디자인시스템 Input/textarea 그대로
- 이름을 넣기 전에는 [싸인 만들기]/[도장 만들기]가 꺼짐 (button_primary disabled · 불투명 0.6) · 글자를 넣으면 켜지고 다 지우면 다시 꺼짐 (2026-11-27)

**업로드**
- 점선 칸을 누르거나 파일을 끌어다 놓으면 이미지를 고름 (jpg · jpeg · png · svg · 2MB 이하)
- 맞는 파일이면 칸 안에 미리보기가 나오고 [이미지 업로드]가 켜짐 · 오른쪽 위 둥근 버튼으로 지우기

버튼 상태: 기본 #1B52ED · 마우스 올림 #1E4BC9 · 누름 불투명 0.9 · 꺼짐 불투명 0.6 (디자인시스템 button_primary 그대로)

## Figma와 다르게 정한 것
- 만드는 방법 제목: Figma는 싸인 그리기만 좌우 여백 0, 나머지 탭은 2 → 탭을 바꿀 때 제목이 2px 움직여서 모든 탭을 2로 맞춤 (2026-11-27)
- 스크롤바 자리를 늘 비워 둠(`scrollbar-gutter: stable`) — 탭마다 페이지 길이가 달라 스크롤바가 생겼다 없어지면서 화면이 옆으로 흔들리던 것을 막음 (2026-11-27)
- 탭(Segmented Control)에는 마우스 올림 효과 없음 — 고객센터 탭과 같게 뺌 (2026-11-27)
- 싸인 그리기 푸터 가운데 제목: Figma는 "고객센터"인데 다른 탭 화면처럼 "공지사항"으로 씀
- 도장 탭 만드는 방법 글자 굵기: Figma는 Light 인데 다른 탭과 같게 Regular 로 씀
- 카드 그림은 시안 예시 그림 그대로 (싸인 "예스폼" · 도장 "홍길동인") — 입력한 이름으로 바뀌지 않음
- 배너 배경: 사진 · 특허증 · 그러데이션을 그림 한 장(`banner-bg@2x.jpg`)으로 합침. 글자는 HTML
