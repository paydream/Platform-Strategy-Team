## 카드 = 메인_검색화면 시안01 카드 재사용

- `01_예스폼/메인_검색화면/시안01-1`(전환 바 "시안01")의 **AI로 초안 생성하기 카드**를 모양 · 치수 · 데이터 그대로 가져왔습니다. Figma 카드 이름도 "시안01 카드 01 ~ 28"(247.6 × 164)로 같습니다.
  - 흰 바탕 · 테두리 1px #f1f2f4 · 모서리 12 · 여백 4 · 높이 164
  - 위 줄(높이 32 · 관심분야 연한 색 · 모서리 8) = 관심분야 이름(가장 진한 색)
  - 흰 박스 = 제목 17px + 꺾쇠 16 · 설명 2줄 · 업종 글자
- 데이터 28장(업종 14종 × 2장)은 시안01-1 `PACKAGE_CARDS` 그대로(`js/main.js`). 새로고침할 때마다 섞고, 같은 제목이 바로 옆에 붙지 않게 합니다.
- 시안01-1과 다른 점: 광고 카드는 Figma에 없어서 뺐습니다. 화면이 좁을 때 오른쪽이 잘리는 대신 **줄바꿈**합니다(아래 "폭에 따라").

## 동작

- **추천 카드**: 4장씩 4묶음(16장). 화살표 · 점으로 넘깁니다. 첫 묶음에서는 왼쪽 화살표가, 마지막 묶음에서는 오른쪽 화살표가 옅어집니다(Figma 왼쪽 화살표 40%).
- **탭**: 누르면 파란 글자 + 아래 3px 줄, 목록 제목이 "관심분야 / 시즈널 / MY 프롬프트"로 바뀌고 카드를 다시 섞습니다.
  - 관심분야 · MY 탭 → 업종 · 관심 분야 상자 / **시즈널 탭 → 관심 분야 · 월 상자**(아래 "시즈널 탭").
- **필터 버튼**: 지금 탭의 상자를 접고 폅니다(처음엔 펼침 — Figma와 같음). 접은 채로 탭을 바꾸면 계속 접혀 있습니다.
- **업종 · 관심 분야 체크**: 고르면 아래 카드가 걸러집니다. 같은 묶음 안에서는 "또는", 업종과 관심 분야 사이는 "그리고"로 거릅니다. 고르면 개수가 실제 카드 수로 바뀌고, 다 풀면 1,234로 돌아갑니다.
  - 이름이 조금 달라도 맞춥니다: 체크 "건설·시공" → 카드 "건설·시공" · "건설·부동산·시공", 체크 "교육·학원·학교" → 카드 "교육·학교·학원".
- **검색**: 검색어를 넣고 Enter → 제목 · 설명 · 업종 · 관심분야에서 찾습니다. 맞는 카드가 없으면 "조건에 맞는 프롬프트가 없어요" 안내.
- 인기순 · 프롬프트 더보기 · 로그인 버튼은 화면 확인용이라 실제 동작은 없습니다.

## 시즈널 탭 (Figma 6796:49709)

- 시즈널 탭을 누르면 업종 상자 대신 **관심 분야 9개 · 월 12개** 상자가 나옵니다. 월은 한 줄 6칸(1920에서 칸 폭 289 · 좁으면 칸 수를 줄임).
- 처음엔 Figma처럼 **HR 관리·채용 · 회계·경리·재무 실무 · 2월**이 체크된 상태(아직 적용 전이라 카드는 전체)입니다.
- 체크하면 아래 줄에 **고른 항목 칩**이 생기고, 칩의 X를 누르면 그 체크가 풀립니다. 오른쪽 **"적용하기 (N건)"**의 N은 체크할 때마다 바로 바뀝니다.
- **적용하기**를 눌러야 카드가 걸러집니다(같은 묶음 안은 "또는", 관심 분야와 월 사이는 "그리고"). **초기화**는 체크를 모두 풀고 전체 카드로 돌아갑니다.
- 시즈널 탭 카드의 **아래 줄은 업종 대신 시즌(월) 이름**입니다(Figma 6796:49798 "2월 연말정산 마감 및 봄맞이 준비").
- 카드별 시즌은 `js/main.js`의 `SEASON_OF`에서 정합니다. Figma 카드에 적힌 것(생산 일보 1월 · 표준 근로계약서 2월 · 솔루션 도입 제안서 2월 · 상가 임대차 계약서 3월 · 시스템 장애 보고서 3월)은 그대로, 나머지 23장은 문서 쓰임에 맞는 달로 2~3장씩 나눴습니다.
- 예시 카드가 28장뿐이라 체크를 여러 개 하면 건수가 0~몇 건으로 적게 나옵니다(0건이면 안내 문구).
- Figma의 칩은 "HR · 회계 · 현장"인데 체크는 "HR · 회계 · 2월"이라 서로 달라서, 칩은 **실제 체크한 항목**을 따라가게 했습니다.

## Figma에 없어서 정한 것

- **추천 카드 내용**: Figma는 같은 예시 카드("마케팅 회사소개서") 4장이라, 제목 "2027 상반기 채용 준비"에 맞는 채용 준비 프롬프트 16장으로 채웠습니다(`RECO_CARDS`). 배지 색은 관심분야 색(연한 배경 + 메인 색), 공공행정은 Figma 색(#fff5eb / #f6972b) 그대로.
- **체크한 상태**: 처음엔 직접 정했는데, 시즈널 화면(6796:49718)에 체크 모양이 있어서 그대로 맞춤 — 파란 상자(#0472e3 · 모서리 5) + 흰 체크. 관심분야 탭 체크도 같은 모양.
- **관심 분야 "법부·계약·지식재산"** → Figma 오타로 보고 "법무·계약·지식재산"으로 고쳤습니다(카드 이름과 같게).
- 검색창을 누르면 파란 테두리.
