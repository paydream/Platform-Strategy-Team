# 예스폼싸인 메인

`index.html`을 브라우저로 열면 됩니다. 메인 폴더에는 HTML 이 `index.html` 하나만 있습니다.

## 폴더 정리 (2026-10-26)

- 메인 폴더 맨 위에는 `index.html`(시안 전환 화면) 하나만 둡니다.
- 시안 두 파일은 `backup/` 으로 옮겼습니다: `backup/index1.html`(시안01) · `backup/index2.html`(시안02). **`index.html` 이 이 두 파일을 불러오니 지우면 안 됩니다.**
- 경로: `backup/` 안의 두 파일은 `../css/` · `../js/` · `../images/` 로 메인 폴더의 스타일 · 스크립트 · 그림을 그대로 씁니다(그림을 따로 복사하지 않음). 2번째 섹션 계약서 그림은 `js/main.js` 가 자기 위치(`js/`)를 기준으로 경로를 만들어서, 어느 폴더에서 열어도 맞습니다(`YS_ROOT`).
- 옮기기 전과 후 화면을 비교해 둘 다 똑같이 보이는 것을 확인했습니다.
- 예전 `예스폼싸인_메인.html` 은 `v01/index.html` 과 완전히 같은 파일이라 따로 옮기지 않았습니다(백업은 `v01/`).

## 시안 전환 (2026-10-26)

`index.html` 은 이제 **시안 전환 화면**입니다. 화면 아래 가운데 버튼으로 시안을 바꿉니다.

| 탭 | 파일 | 스타일 |
|---|---|---|
| 시안01 | `backup/index1.html` | `css/style.css` |
| 시안02 | `backup/index2.html` | `css/style2.css` |

- 시안마다 따로 띄워서(iframe) 스타일이 서로 섞이지 않습니다. `js/main.js` 와 `images/` 는 같이 씁니다.
- **고칠 때**: 시안01은 `backup/index1.html` · `css/style.css`, 시안02는 `backup/index2.html` · `css/style2.css` 를 고칩니다. `index.html` 은 전환 버튼만 들어 있습니다.
- 전환 버튼은 어두운 바탕(#1D1F20) · 선택된 시안은 파란색(#2D62FA)
- 주소 뒤 `#01` / `#02` 로 바로 열 수 있고, 마지막으로 본 시안을 기억합니다. 버튼에서 ←/→ 키로도 바뀝니다.
- 시안을 하나만 크게 보려면 `backup/index1.html` · `backup/index2.html` 을 바로 열면 됩니다 (`#grid` · G 키 경계 보기도 이쪽에서).

## [내부] 그리드 — 2026-10-23부터 메인 페이지 기준

- **[내부] = 폭 1280px 고정, 그 안에 좌우 여백 10px** → 콘텐츠는 가운데 1260px 고정. (반응형 아님)
  - 1920 화면 → [내부] 320 ~ 1600 · 콘텐츠 330 ~ 1590.
  - 화면이 1280px보다 좁아도 줄지 않고 가로 스크롤이 생깁니다. 섹션 안 치수도 모두 고정 px입니다.
- 모든 섹션은 **바깥 + [내부]** 두 겹입니다.
  - 바깥: 배경색 · 배경 그림 · 위아래 여백(80)만 맡고, 화면 끝까지 깔립니다.
  - [내부] `.inner`: 콘텐츠는 이 안에서만 정렬합니다. 좌우 여백은 [내부]가 맡아서 바깥 섹션의 좌우 여백은 0입니다.
- 적용한 섹션 (위에서부터): GNB · 히어로 · 업로드 · 전자도장 · 분야별 계약서 · 진행 상태 · 법적 효력 · 프리미엄 회원 · 푸터
- 새 섹션을 더할 때도 같은 구조로 넣으면 됩니다.

```html
<div class="섹션 이름">          <!-- 배경 · 위아래 여백 -->
  <div class="inner"> … </div>   <!-- [내부] 1280 (안쪽 좌우 10 → 콘텐츠 1260) -->
</div>
```

- 폭을 바꾸려면 `css/style.css` 맨 아래 `--ys-inner`([내부] 전체 폭 1280px) · `--ys-gutter`(안쪽 좌우 여백 10px) 두 값만 고치면 됩니다.
- **경계 보기**: 주소 뒤에 `#grid`를 붙이거나(`index.html#grid`) 키보드 **G**를 누르면 [내부] 끝(1280)은 빨간 실선, 콘텐츠 끝(1260)은 빨간 점선으로 보입니다. 다시 G를 누르면 꺼집니다.

  4. 확인 후 전송 — 서명 · 도장이 들어간 계약서 + 종이비행기 + "서명 요청" / 전송하면 참여자에게 서명 요청이 전달됨
  - 위아래 여백: 히어로 끝 → 카드 80 · 카드 끝 → 다음 섹션(표준 계약서) 타이틀 80
