### 등장 방식 — 위쪽 검은 바의 탭으로 고름 (검토용 · 실제 화면에는 없음)

| 탭 | 언제 | 어떻게 |
|---|---|---|
| **시안01** | 페이지에 들어올 때 한 번 | 폼은 왼쪽 아래, 도장은 오른쪽 아래에서 **대각선**으로 동시에 떠오름 |
| **시안02** | 스크롤을 100px 넘게 내릴 때 | 폼 · 도장 · 말풍선이 함께 48px **아래에서 위로** 떠오름 · 맨 위로 올리면 다시 숨음 |

- 말풍선 효과: 시안01 은 **글자 깜빡임**(1.6초마다 글자 100% → 35% → 100%) · 시안02 는 **빛 지나가기**(2.2초마다 흰 빛줄기가 말풍선 위를 왼쪽 → 오른쪽으로 훑고 지나감)
- 마지막으로 본 탭 기억 · 주소 뒤 `#sian2` 처럼 붙이면 그 탭으로 열림
- 다 나온 뒤 모습은 두 시안이 픽셀까지 같음 (움직임만 다름)

#### 시안01 — 페이지에 들어올 때

| 시작 | 무엇 | 움직임 |
|---|---|---|
| 0.10초 | 폼 타일 · 도장 (동시에) | 폼은 왼쪽 아래(-24, +28), 도장은 오른쪽 아래(+24, +28)에서 대각선으로 떠올라 제자리로 · 약 0.2초 만에 자리에 닿고 0.5초 안에 멈춤 |
| 0.50초 | 말풍선 | 6px 아래에서 떠오르며 나타남 |
| 1.30초~ | 말풍선 글자 | 글자 깜빡임 (계속) |

- 그림 2장을 다 불러온 뒤 시작 (늦어도 1.5초 뒤) · 새로고침하면 다시 나옴
- 위쪽 바의 **등장 다시 보기** 버튼으로 처음부터 다시 볼 수 있음 (시안01 탭에서만 보임)

#### 시안02 — 스크롤할 때

| 시작 | 무엇 | 움직임 |
|---|---|---|
| 스크롤 100px 넘김 | 폼 타일 · 도장 · 말풍선 (함께) | 48px 아래에서 위로 떠오르며 나타남 · 크기 90% → 100% · 약 0.5초 안에 멈춤 |
| +0.40초~ | 말풍선 | **빛 지나가기** — 흰 빛줄기(박스 폭 40% · 20° 기울임)가 0.4초에 바로 한 번 지나가고, 그 뒤 2.2초마다 한 번씩 (계속) · 말풍선 크기 · 위치는 그대로 |
| 다시 100px 이하로 | 전체 | 셋 다 같이 0.25초 동안 아래로 빠지며 숨음 (숨은 동안에는 누를 수 없음) |

- 처음 화면(맨 위)에서는 숨어 있음 · 나타나는 기준 100px 은 `js/floating.js` 의 `SHOW_AT`

#### 두 시안 공통

- 움직임은 같은 스프링 곡선 — 목표 자리를 1~2px 정도만 살짝 지나쳤다 돌아와서 딱딱하지 않게 멈춤
- 폼 · 도장 이동 0.6초 · 말풍선 이동 0.5초 · 찌그러짐(가로세로 따로 늘이기)은 쓰지 않음
- 움직임이 끝나면 그림이 원래 그림 그대로 보임 (움직임 없는 화면과 픽셀까지 같음)
- 뱃지에 마우스를 올리면 시안01 은 깜빡임을 멈추고 글자를 또렷하게, 시안02 는 빛줄기를 멈추고 감춤
- 움직임 줄이기 설정이면 시안01 은 처음부터 그대로 보이고, 시안02 는 움직임 없이 바로 나타나고 숨음 (깜빡임 · 빛 지나가기 없음)
- 시간 · 거리 값은 `css/floating.css` 의 "시안01" · "시안02" 부분에 모여 있음
