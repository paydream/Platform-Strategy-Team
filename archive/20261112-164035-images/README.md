```
템플릿 만들기 — index.html 모달 [다음]
  ├ 대량 전송 → pages/upload.html?type=bulk&flow=tpl   ─ [다음] → participants.html        ─ [다음] → signing.html?flow=tpl ─ [다음] → review.html
  └ 일반 계약 → pages/upload.html?type=normal&flow=tpl ─ [다음] → participants-normal.html ─ [다음] → signing.html?flow=tpl ─ [다음] → review.html

계약하기 — index.html 행의 [계약 시작하기]
  └ pages/upload.html?type=…&tpl=템플릿명&roles=역할 ─ [다음] → participants-send.html ─ [다음] → signing.html?flow=send

단계 화면의 [나가기] → 나가기 확인 모달 → [나가기] → index.html
```
- 템플릿 만들기 흐름(일반 계약 · 대량 전송 모두)은 2단계 [다음] → signing.html, 위쪽 2단계 이름이 **"역할 설정"** (Figma `54361:34379`)

- participants.html · participants-normal.html 은 템플릿 만들기 때만 나옴 ([계약하기]로는 participants-send.html)
- 참여자 설정에서 입력한 역할은 주소 뒤 `?d=…` 로 signing.html 에 넘어갑니다.
- 템플릿 만들기는 signing.html [다음] → 4단계 검토(review.html). [계약하기]는 검토 화면 디자인이 없어 signing.html 의 [다음]이 넘어가지 않습니다.

## 템플릿 관리 (index.html) 동작

- **상단 헤더** — 화면 위에 고정되어 스크롤해도 그대로 보임
- **템플릿 만들기** — 누르면 "어떤 템플릿을 만들까요?" 모달이 열림
  - 일반 계약 / 대량 전송 카드 중 하나를 고름 (열 때마다 일반 계약부터)
  - 취소 · 다음 · 바깥 어두운 곳 · Esc 로 닫힘. 다음 화면은 아직 없어 닫히기만 함
- **표 머리** — 맨 왼쪽에 핀 아이콘 (Figma `54255:26690` · 25° 기울어진 핀)
- **역할 칸** — 같은 종류(미리 입력 · 보낼 때 입력) 역할이 2개 이상이면 "첫 역할 외 N개" 라벨 하나로 묶어 보임 (마우스를 올리면 전체 역할 이름 · [계약 시작하기] 때는 모든 역할이 넘어감)
- **역할 안내 툴팁** — 표 머리 "역할" 옆 ⓘ 에 마우스를 올리면 보임 (키보드 Tab 으로 가도 보임 · Figma `54279:31909`)
- **행 펼치기** — 행을 누르면 아래에 [계약 시작하기] · 수정하기 · 템플릿명 변경 · 삭제 메뉴가 펼쳐짐 (한 번에 한 행, 처음엔 모든 행이 닫힌 상태)
- **핀** — 마우스를 올리면 파란 선, 누르면 파랗게 채워지며 상단 고정 표시가 켜지고 꺼짐 (행 순서는 그대로)
- **템플릿명 검색** — 입력한 글자가 들어간 템플릿만 보임 (Esc 로 지움)
- **템플릿 빈 화면** — 템플릿이 하나도 없으면 표 대신 "아직 저장된 템플릿이 없습니다" 안내와 만드는 순서 3단계(문서 업로드 · 참여자 설정 · 서명 조건 설정)가 보임 (Figma `54169:29120`)
  - 확인용으로 `index.html?empty` 로 열면 템플릿이 있어도 빈 화면으로 보임
  - 그림 3장은 Figma 그대로 내보낸 이미지 (`images/empty-upload@2x.png` · `empty-participants@2x.png` · `empty-signing@2x.png`)

## 문서 업로드 (upload.html) 동작

- **내 템플릿 [선택하기]** — 위 업로드 칸 자리에 "선택한 문서"로 들어가고 버튼은 [선택됨](파랑)으로 바뀜
  - 템플릿은 한 개만 · 다른 템플릿을 고르면 바뀜 · [선택됨]을 다시 누르거나 목록의 X 로 빠짐
- **내 PC 업로드 · 끌어 놓기** — 고른 파일도 같은 목록에 들어감 (템플릿 포함 최대 10개)
- 문서가 하나라도 있으면 아래 **[다음]** 이 켜지고, 누르면 참여자 설정으로 이동
- 템플릿 관리에서 **[계약하기]** 로 오면 그 템플릿이 처음부터 선택된 상태 (템플릿명이 같게 보임)
  - 내 템플릿 목록에 같은 이름이 있으면 그 행을 맨 위로 올려 고르고, 없으면 맨 위에 그 템플릿 행을 만들어 고름
- 문서명 검색 · 헤더와 아래 버튼 줄은 화면에 고정
- **샘플 문서 탭** — 카테고리 · 문서명 검색 · 여러 개 선택 (선택한 문서 목록에 같이 들어감, 전체 10개까지)
  - 아래 쪽 번호는 디자인대로 "/ 48"만 보임 (다른 쪽은 없음)

## 일반 계약 참여자 설정 (participants-normal.html)

- 문서 업로드에서 넘어오면 빈 참여자 카드 1개로 시작. 이 화면을 바로 열면 Figma 와 같은 4명 (처음 모습은 `js/participants-normal.js` 의 `people` 에서 고침)
- 서명 순서 카드 — 순서대로 / 순서없이 중 하나 고름
- 역할을 적으면 카드 머리에 역할 라벨이 붙음
- [이름 추가하기] · [연락처 추가하기] → 그 칸이 생기고 버튼은 사라짐 · 그 칸이 빈 채로 다른 곳을 누르면 다시 [추가하기] 버튼으로 돌아감
- 서명 요청자 본인 스위치 → 이름 · 연락처가 김예스 · 010-1234-1234 로 잠김 (한 명만 켤 수 있음)
- 휴지통 → 참여자 빼기 (한 명은 남김) · [서명 참여자 추가하기] → 빈 카드 추가 (최대 10명)
- [다음] → 역할이 빈 카드에 빨간 테두리와 "역할을 입력해주세요." · 모두 적었으면 서명 조건 설정으로 이동

## 계약하기 참여자 설정 (participants-send.html)

- 템플릿 관리에서 [계약하기]를 누른 템플릿의 역할마다 참여자 카드가 하나씩 생김 (카드 머리에 대량 전송 · 일반 계약 라벨)
  - **실선 역할** (이름까지 정해진 역할) → 템플릿에 넣어 둔 이름 · 연락처가 읽기 전용(회색)으로 채워져 있음 (예: 계약자 홍길동 · 010-1234-1234, 추가 인증 2개 켬 — `data-auth`, 서명 요청자 본인 — `data-self`)
  - **점선 역할** (역할만 있는 역할) → 이름 · 연락처 빈 칸
  - 미리 입력한 이름 · 연락처는 `index.html` 역할 라벨의 `data-name` · `data-contact` 에 있음 (라벨에 마우스를 올리면 보임)
  - 바로 열면 Figma 예시 3명 (서명 요청자 본인 · 근로자 · 역할 미입력)
- 칸: 이름* · 연락처* · 서명 유효기간*(기본 14일) · 전달 메시지 — 서명 요청자 본인은 이름 · 연락처가 잠김
- 추가 인증: 본인은 안내 문구 · 설정한 인증은 파란 라벨 · 없으면 오른쪽 [설정하기]
- 휴지통 → 빼기 (한 명은 남김) · [서명 참여자 추가하기] → "역할 미입력" 카드 (최대 10명)
- [다음] → 이름 · 연락처 · 서명 유효기간이 빈 칸은 빨간 테두리 · 모두 채웠으면 서명 조건 설정으로 이동 (역할 · 이름 · 연락처를 넘김)
- [설정하기] · [주소록에서 불러오기]는 디자인이 없어 눌러도 동작하지 않음

## 서명 조건 설정 (signing.html)

- **왼쪽 패널은 흐름마다 다름**
  - 템플릿 만들기 (Figma `54279:31589` · `54436:48805`) — 역할마다 "역할" 상자가 하나씩 (서명 요청자 본인 · {역할명} · 이름 · 연락처) + 상자마다 입력 항목
    - 한 번에 한 상자만 펼쳐짐. 처음엔 마지막(새로 추가한) 역할 상자가 펼쳐지고 그 역할의 도장이 골라져 있음
    - 상자의 입력 항목을 누르면 오른쪽 "역할 선택"이 그 역할로 바뀜
  - 계약하기 (Figma `54376:36659` · `54436:47492`) — "서명 참여자" 카드가 참여자마다 하나 (맨 위 역할 라벨 · 서명 요청자 본인 → {이름} → 연락처)
    - 카드마다 입력 항목이 있고, 카드 머리를 누르면 접히고 펼쳐짐
    - 카드의 입력 항목을 누르면 오른쪽 "역할 선택"이 그 참여자로 바뀜 (이름 + 역할로 보임)
  - 색은 참여자 순서대로 빨강 · 노랑 · 주황 … (Figma 색상 순서 `53693:29199`)
- **역할** — 참여자 설정에서 입력한 역할 · 이름 · 연락처가 왼쪽 패널과 오른쪽 "역할 선택"에 들어감
  - 이름 · 연락처 · "서명 요청자 본인" 표시도 같이 들어감 (대량 전송은 "이름 · 연락처는 대량 전송 시 입력")
  - 처음 골라진 역할: 템플릿 만들기는 마지막 역할 · 계약하기는 서명 요청자 본인(없으면 첫 참여자)
  - 역할 상자는 Figma Select box(`54287:33348`) 모양 — 역할 + 이름 · 연락처 (서명 요청자 본인이면 맨 위에 라벨이 붙어 조금 높아짐)
  - 역할마다 색이 다름. Figma 색상 순서(`53693:29199`) 빨강 · 노랑 · 주황 · 초록 · 청록 · 파랑 · 남색 · 보라 · 자주 · 갈색 (`js/signing.js` 의 `COLORS`)
  - 오른쪽 "역할 선택"을 바꾸면 문서의 도장 칸 색도 바뀌고, 본인 역할일 때만 아래 안내 문구가 보임
- 이 화면을 바로 열면 Figma 예시(회사 · 홍길동 · 서명 요청자 본인)로 보임

  - 도장 → 도장 설정 (문서 위 도장 칸은 이때만 보임)
  - 공통 항목 [텍스트] → 텍스트 · 공통 항목 설정 (Figma `54436:52104`) — "공통 항목은 선택 불가" · 읽기전용 고정 · 정렬 왼쪽 · 가운데 · 오른쪽
  - 공통 항목 [날짜] → 날짜 · 공통 항목 설정 (Figma `54436:50730`) — 자동 완성(입력 방식) · 표기 방식

  - [계약하기] 서명 요청자 본인의 도장 → 도장 설정 (Figma `54436:47492`)
    - "역할 선택" 대신 "서명 참여자 선택" · 아래에 지금 서명 / 계약 시 서명

    - 계약 시 서명: 디자인이 없어 상자 · [서명 선택하기] · 아래 안내 문구만 숨김
    - 모달의 보관함 외 탭(일반도장 · 법인도장 · 업로드)은 디자인이 없어 탭 표시만 바뀜
    - 문서에는 본인 도장 칸이 2개 (위쪽 칸 + 고른 칸) · 본인 카드 입력 항목은 싸인 (1) · 도장 (2)
  - 그 밖 항목(싸인 · 자필 작성 · 날짜 등)은 설정 디자인이 없어 눌러도 바뀌지 않음
  - 글자 색 칸을 누르면 색 고르기 창 · 정렬 셋 중 하나 고름 (정렬 순서는 Figma 대로 오른쪽 · 가운데 · 왼쪽)
  - 자동 완성 · 폰트 목록은 Figma 값 하나만 넣음 (글자 크기는 8~24px)
- 위쪽 돋보기로 50~200% 확대/축소 · 공통 항목 · 역할 ⓘ 에 마우스를 올리면 안내
- 삭제 · 복사 · 되돌리기 · 미리보기 · 도움말은 디자인만 있어 눌러도 동작하지 않음
- 계약서와 도장은 Figma 에서 받은 그림 (`images/doc-contract.png` · `images/stamp-hong.png`)

## 검토 (pages/review.html) — 템플릿 만들기 4단계

- 앞 단계에서 넘어온 내용이 채워짐: 문서 이름 · 서명 순서 · 역할 · 추가 인증 · 템플릿 유형
- 템플릿명: 문서 이름이 처음 값 (최대 50자, 글자 수 표시) · [자주 사용하는 템플릿에 추가] 누르면 켜고 끔
- 역할 (n): 역할마다 카드 — 순번 · 역할명 · 서명 요청자 본인 또는 이름 · 연락처 · 추가 인증 (없으면 "추가 인증 없음")
  - 카드 위 띠 · 순번 색은 역할 순서대로 (서명 조건 설정과 같은 색)
- 고정 첨부 문서 X → 빼기 · [미리 보기]는 디자인이 없어 동작하지 않음
- [계약 작성 완료] → 템플릿 관리(index.html)로 돌아감
- 바로 열면 Figma 예시(역할 3개)로 보임

## 나가기 확인 모달 (단계 화면 모두)

- 아래 [나가기] → "현재 작성하신 계약이 저장되지 않습니다." 모달 · 취소 · 바깥 · Esc 로 닫힘 · [나가기] → index.html

## 표 고치는 법

`index.html` 의 `<li class="row">` 하나가 한 행입니다.
- 유형 라벨: `type type--bulk`(대량 전송) · `type type--normal`(일반 계약)
- 역할 라벨: `role`(정보를 미리 입력한 역할, 실선 — `data-name` · `data-contact` 에 이름 · 연락처) · `role role--empty`(보낼 때 입력, 점선)
- 핀 켠 상태: `pin is-on` + `aria-pressed="true"`
- 처음부터 펼쳐 둘 행: `row is-open`
